# i18n Rules

- When making frontend modifications, only add/update **French** translations.
- Do NOT update other language files (en, es, it, de, tr) unless explicitly requested.
- Toujours tutoyer l'utilisateur (jamais de vouvoiement). Ex: "Entre ton email", "Tes decks", "Connecte-toi".
